# Discover.World

A travel discovery project that started as a Web Technologies project at FH Joanneum and is now becoming a long-term project that I want to develop further throughout my studies.

## About the project

Discover.World is a travel platform concept focused on discovering cities, places and experiences.

The first version was created during my second semester in the Web Technologies course at FH Joanneum. At that point, the main goal was to build a functional and visually appealing web application using HTML, CSS and JavaScript.

I liked the idea behind the project enough that I did not want to leave it as a finished university assignment. Instead, I want to keep developing it as I learn new technologies and gradually turn it into a larger application.

The current version is still a frontend prototype, but it is the starting point for that process.

## What can you do right now?

The current web version includes:

- Explore different destinations
- City pages for Graz, Tokyo and Nairobi
- Browse places by category
- Filter and sort places
- Save favorite places using browser storage
- Interactive image galleries
- Full-screen image modals
- Light and dark mode
- Responsive layouts for different screen sizes
- World and city slideshows
- City search and navigation
- Upload personal photos locally in the browser

Some of these features are intentionally still client-side. For example, saved places and uploaded photos currently use `localStorage`, so the data is stored only in the user's browser.

The contact form is also currently a frontend prototype and does not send messages to a backend service yet.

## Why I am continuing this project

One of the reasons I want to keep working on Discover.World is that it gives me a project that can grow together with my skills.

Instead of creating a completely new project every time I learn a new technology, I want to see how the same idea can evolve from a simple web application into a larger software project.

The next major step is to move beyond the current frontend and start working with a backend, database and API. After that, I want to use what I am learning in mobile development to build an Android version.

iOS is a possible future step as well.

This means that the project will probably change quite a lot over time. This repository documents that process.

## Project background

Discover.World was originally created as part of the Web Technologies course during my second semester at FH Joanneum.

The current version builds on that original idea, but the project is now being continued as a personal long-term development project.
